Rugol HRO — al abrir, esto es lo que ves

La pantalla de inicio ahora ES la sala de reclutamiento. Un solo lugar: el flujo, qué está conectado, qué link compartir y qué hacer. En español neutro.

Responde tus preguntas, de un vistazo

  • ¿Cómo funciona? → el flujo de 5 pasos arriba: Llega el candidato → Screening → Sofía entrevista → Pipeline automático → Terna.
  • ¿Qué está conectado / dónde lo configuro? → panel "Qué está conectado": Anthropic (activo), ElevenLabs·Sofía (con "Configurar →" a Settings), Telegram. Un solo lugar.
  • ¿Qué link comparto para la entrevista? → caja "Link de entrevista" con hro-entrevista.vercel.app + botones Copiar / Abrir.
  • ¿Qué hago ahora? → acciones rápidas: ver candidatos, ver entrevistas, sincronizar, configurar a Sofía.
  • Voseo: eliminado de toda la app. Español neutro.

Para activarlo

  • En Settings → "Entrevistas por voz · Sofía" pega tu API key de ElevenLabs + el Agent ID. El panel pasará a verde "conectado".
  • Comparte el link de entrevista; cuando el candidato termina, "Sincronizar con ElevenLabs" lo trae puntuado a Entrevistas.
