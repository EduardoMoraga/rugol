Rugol HRO — conectores y flujos a pedido

No hay que codear un Pandapé custom: le describes la integración a un agente conector (Claude Code) y él la arma y la ejecuta, con tus credenciales, dejando los CVs en la búsqueda.

Probado: al conector le pedí "consulta la API de GitHub y guarda un resumen" → armó el flujo, lo ejecutó y dejó el archivo con los datos reales (Anthropic · 91 repos). Pandapé/Drive/cualquier API es el mismo mecanismo.

En la app — Fuente de CVs de una búsqueda

Tres botones: Conectar carpeta (local o Drive/OneDrive sincronizado) · Conectar fuente externa (API / Pandapé / Web) · Analizar CVs.

Cómo conectas cada cosa

Google Drive / OneDrive
  1. Conectar fuente externa → tipo "Drive/OneDrive" → elige la carpeta donde Drive/OneDrive sincroniza los CVs. (O Conectar carpeta directo.)
Pandapé (tu integración custom, ahora sin codear)
  1. Abre la búsqueda → Conectar fuente externa → tipo API / Pandapé.
  2. En "¿Qué quieres traer?": "Trae los CVs de la vacante 'Promotor Acme' de Pandapé".
  3. Pega tu token de Pandapé en credenciales (se guarda solo en tu equipo).
  4. Construir y traer CVs → el agente arma el flujo, baja los CVs a la búsqueda.
  5. Analizar CVs → el screener los evalúa y carga como candidatos.
Cualquier otra API / web
  1. Mismo flujo, tipo "Web / personalizada": describe qué traer + credenciales si aplica. El agente construye el conector.
